# Lintel 菜单语义与分发实施计划

本批继续复用现有运行时、窗口、菜单控制器、AccessKit、portable 与 managed install 实现，保持业务通过普通 Message/Task 接入。按用户要求使用多个 agent，跳过 AI Dev Loop，不修改原仓库业务、不提交或发布。

| 范围 | 实施方式 | 验收 |
|---|---|---|
| 菜单原生无障碍 | 从 MenuSpec 和实际布局产生原生菜单层级与状态；辅助动作经弱引用有界队列交回 UI；业务继续使用现有 menu_bar | 支持角色/动作以锁定 AccessKit 源码为准；稳定节点、模型变更、禁用、关闭、展开/选择与多菜单模态回归；macOS 原生 AX |
| Windows 分发目录 | 将已验证 portable、固定同架构工具和更新公钥组成可审查目录，记录最终字节哈希；沿用现有安装保护 | 真实文件夹模型与失败不覆盖测试；Windows 类型检查；不宣称 MSI/NSIS、证书链信任或 CEF 原生运行 |
| 集成与发行内容 | 更新业务说明、独立示例及 CLI 随包源码；保留公开/旧依赖检查 | 定向测试后运行适用检查，独立生成工程编译和内容哈希；保存验收证据 |

原生辅助动作不能直接在系统回调线程执行业务。菜单打开时仍需隔离背景动作，关闭后正常键盘/IME 不丢失。源码、软件渲染回归、macOS 原生 AX、屏幕阅读器语音以及 Windows/Linux 原生运行分别记录。
