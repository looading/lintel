# Lintel 基础能力实施与验收

目标是把现有运行时上的窗口、插件、任务、WebView 和常用系统服务接成可供独立应用使用的接口。保留已验证的渲染、CEF 和发行链路。

用户要求本轮使用多个 agent 协作，并跳过 AI Dev Loop。本轮直接保存测试、独立示例和平台验证结果。

| 范围 | 负责人 | 交付与验证 |
|---|---|---|
| 窗口与输入 | windows agent | 轻量多窗口入口、窗口事件与关闭确认、重开和最后窗口退出，复用 iced 路由 |
| 生命周期与任务 | runtime agent | 可失败插件启动、冲突拒绝、失败清理，以及应用/窗口/页面任务取消 |
| 桌面系统服务 | desktop agent | 菜单、托盘、快捷键、剪贴板、文件选择、通知、打开链接、凭据与单实例 |
| 桥接与服务 | root | 有界异步命令、页面失效取消、权限、配置存储、网络下载、诊断及实际入口整合 |
| 发行与证据 | root | 模板和便携 CLI 归档包含新增接口，保留签名/更新回归，逐项记录实测平台 |

## 验收方式

在公开图形依赖配置下编译框架和示例。对新增生命周期、窗口状态、取消、来源约束、下载失败及迁移写入失败做回归测试。独立启动原生多窗与 WebView 并检查日志和关闭后的进程。使用已有打包、更新和签名测试复核发行路径。证书、公证以及其他系统的运行验收按实际环境记录。
