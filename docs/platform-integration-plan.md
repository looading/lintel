# Lintel 平台接入补齐计划

本轮继续在独立项目内补齐能力。保留现有窗口、渲染与 CEF 实现，业务通过可选模块和普通 Message 接入。按用户要求使用多 agent，跳过 AI Dev Loop。

| 范围 | 交付 | 验收 |
|---|---|---|
| 自定义控件语义 | 公开轻量语义包装器、受支持的角色与动作；沿用真实布局与节点生命周期 | 自定义控件动作、禁用、密码值隔离、失效动作测试；示例编译和 macOS 原生 AX |
| Linux 窗口菜单 | 调查并复用现有 iced 菜单实现，提供应用内菜单及普通 Message 接口 | 状态/键盘测试、示例编译、Linux 交叉检查；原生桌面会话另记 |
| Windows CEF SDK | 校验官方版本、归档来源与 bootstrap 布局，输出可审查结果 | 官方来源和实际归档校验、错误输入测试；保留 Windows 原生运行门槛 |
| Windows 发行工具 | 显式签名工具接入与可审查计划、验证步骤 | 工具参数和失败路径测试、CLI/Windows 交叉检查；证书签名另记 |
| 集成 | 模板/CLI 分发包含新增接口和文档，保留公开与旧依赖配置 | 定向单测、示例检查、便携生成项目编译，更新能力清单与证据 |

Windows/Linux 测试机当前不可用。交叉编译、工具夹具、真实桌面验收分别记录；不通过编辑状态字段启用未经运行验收的 CEF 发布路径。本轮不改原仓库业务代码、不提交或发布。
